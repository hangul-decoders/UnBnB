  - `processing.py`가 상단에서 `G2P.KoG2Padvanced`를 import → 별도 저장소 clone 필요
  - `rule.py`가 openai, dotenv를 import (8-2 한자 치환은 OpenAI API 사용)
  - 전역 `random`을 써서 시드 고정이 일부만 됨

### 우리 래퍼에서 고칠 점
1. **1-1 된소리**: 초성/중성이 없는 글자(ㅋㅋㅋ, ㅠㅠ 등 자모만 있는 글자)를 `continue`로 버림 → 입력에서 글자가 사라져 정답과 어긋남. NSMC에는 ㅋㅋ·ㅠㅠ가 많아 반드시 수정
2. **2-1 반모음**: 어절의 모든 글자를 바꿔 너무 심함 → 글자 단위 확률로 적용
3. **5-1 야민정음**: 사전에 ㉵, ㈎ 같은 원문자가 섞여 있음 → 토크나이저에서 `<unk>` 가능성. 한글 대 한글 매핑(대↔머 등)만 사용
4. **11 순서 섞기**: 숫자·기호까지 섞어 "10점"이 깨짐 → 한글로만 된 어절에만 적용 (의미 보존 평가 항목과 직결)
5. **적용 비율**: 함수는 어절 전체에 적용되므로, 문장 내 일부 어절만 고르는 비율(KOTOX는 0.4)과 규칙 개수(2~4개)를 래퍼에서 제어
6. **시드**: 전역 `random`을 쓰므로 `random.seed()`로 고정

## ② 갓종대왕 저장소 (github.com/thtl1999/God-sejong)

**결론: LICENSE 파일 없음 → 코드 복사는 하지 않고 특징 참고용으로만 사용 (계획대로).** 마지막 커밋 2020-11.

- 받침 넣기: 단어 전체에 같은 받침 하나를 붙임 (KOTOX는 뒷글자 초성 기준)
- 쉬프트키: 초성(ㄱ→ㄲ 등)뿐 아니라 모음(ㅏ→ㅑ, ㅐ→ㅒ)과 받침(ㅂ→ㅄ)도 바꿈 → KOTOX 1-1에 없는 변형이라 평가 데이터 B/C에서 일반화 확인 포인트
- 야민정음: 한글끼리 매핑(대↔머, 귀↔커, 파↔과, 비↔네, 거↔지 등) 위주 → 우리 야민정음 규칙의 사전 구성에 참고
- 캠브리지: 4글자 이상 단어의 첫·끝 글자 고정, 가운데만 섞음
- 된소리(`duensori.js`), 꼬기(`twist.js`) 파일은 비어 있음 (미구현)
